## 編輯與保存

1. 搜尋物件，或依場景篩選。
2. 按「編輯／換圖」修改名稱、文字與圖片；物件關係可另行編輯。
3. 按「儲存修改」保存至目前瀏覽器。
4. 按「下載 HTML」帶走含修改內容與圖片的完整網頁。
5. 若要更新共享網站，將下載檔案提交為 `docs/index.html`。

瀏覽器草稿不會自動同步到 GitHub，也不是多人即時共編。網頁修改不會自動回寫 Excel。
