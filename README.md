# 我，你，他｜專案百科

遊戲物件符號學百科，提供文字編輯、圖片替換、瀏覽器草稿，以及完整 HTML 下載。

網站目錄為 `docs/`；GitHub Pages 使用 `main` 分支的 `/docs`。
網站網址：<https://mathew0315.github.io/Graduation_project_mkck/>

## 編輯與保存

1. 在網站按「編輯內容」，或開啟條目按「編輯文字」。
2. 更換圖片可在編輯模式下直接點圖片。
3. 按「套用修改」，再按「下載 HTML」取得新版 `index.html`。
4. 將新版檔案提交到本儲存庫的 `docs/index.html`，網站重新部署後即更新。

目前瀏覽器草稿不會直接寫入 GitHub，也沒有多人即時共編。Excel 為原始交付快照，網頁修改不會自動回寫 Excel。

## 收錄內容

- 133 個百科條目、1,908 個物件定義。
- 109 段故事與 31 張製作資料表。
- 既有素材圖片、部分音訊試聽及影片預覽。
- 40 項待確認內容保留註記。

線上版以無損壓縮小檔同時載入完整資料；資料檔在 `docs/data/`。按「下載 HTML」產生的檔案會自動內嵌全部資料，可離線使用。未使用外部圖片服務。
本儲存庫僅含百科交付物，不包含 Unity 遊戲原始專案與快取。
