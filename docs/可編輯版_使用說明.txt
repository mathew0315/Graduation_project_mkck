我，你，他｜可編輯百科

開啟「我你他_專案百科_可編輯版.html」，不需安裝或連線。

修改文字
1. 點底部「編輯內容」。
2. 首頁、故事段落、故事同步旁會出現「編輯」按鈕。
3. 開啟百科條目或物件定義，也可直接按「編輯文字」。
4. 修改欄位後按「套用修改」。按取消可放棄尚未套用的內容。

更換圖片
編輯模式下直接點圖片，或在條目內點「更換首張圖片／新增圖片」。
選擇 JPG、PNG 或 WebP，確認預覽後按「套用修改」。
同一圖片素材的所有引用一起更新，例如圖庫、章節封面、縮圖。
單張最多 20 MB；較大圖片自動縮至最長邊 2,400 像素。
新圖片內嵌於 HTML，不必另外攜帶圖片資料夾。

保存
套用後會嘗試將草稿存於目前瀏覽器；底部會顯示成功或失敗。
要保存成可攜帶的檔案，請按「下載 HTML」。這會下載新檔，不會覆蓋正在開啟的檔案。
下載的新 HTML 包含目前文字、圖片、原有百科資料與編輯工具，之後可以繼續修改。
瀏覽器清除資料、換瀏覽器或換装置可能讀不到草稿，因此離開前請下載新版 HTML。
快捷鍵：Ctrl／Command + S；正在編輯欄位時套用修改，其他時候下載 HTML。

更多
「復原上次修改」：依序撤回本次開啟頁面後套用的修改，包含圖片和匯入。
「備份修改」：下載 JSON 修改備份，不包含完整原始百科。
「匯入修改」：將同版百科的修改備份合併進來。同欄位以備份取代，其餘保留。
跨裝置分享以完整 HTML 最方便；JSON 用於在同版百科間移交修改。

資料同步範圍
百科條目、物件定義、故事全文、故事對照與故事同步的修改會更新網頁內相應表格。
故事全文與故事摘錄分開編輯，避免自動改寫引文。摘錄可到製作資料的「故事對照」更新。
來源檔案清冊、物件識別碼、數字與統計保留唯讀；部分製作資料可以逐筆展開修改文字。
Excel 是原始交付快照，不會隨網頁編輯自動更新。網頁內資料表可匯出 CSV。
原始遊戲專案、圖片檔案與先前交付的故事修訂版均未改動。
這是單機離線編輯頁面，沒有雲端同步或多人即時共編。
